# CurveEditor2 マニュアル

<img src="images/CurveEditor2_screen.png" width="360">

**CurveEditor2** は、AviUtl2 向けイージングエディタ（Rust 製 `.aux2`）です。トラックバー適用は専用の `@カーブエディタ2.tra2` を使用します。

- **バージョン:** 0.9.11（`@カーブエディタ2.tra2` v1.10 / aviutl2-rs 0.47）
- **作者:** by HexBrowns
- **必要環境:** AviUtl2 **2.1.10** 以上

---

## 開き方

- **表示** メニュー → **CurveEditor2**（ウィンドウ配置パネルからも選択可）

起動時はウィンドウを非表示のまま登録します。表示リストに出ない場合は AviUtl2 を再起動してください。

初回起動などで移動方法（`aviutl2.ini` の `[Movement.*]`）を新規登録した場合は、ステータスに再起動案内が出ます。**AviUtl2 を再起動してから**「このトラックに適用」してください。

### 画面の構成（v0.8.0〜）

上から順に固定パネルで並びます。**グラフが中央パネル**なので、ウィンドウを広げた分・
他のパネルを畳んだ分は、すべてグラフの高さになります。

| 位置 | 内容 |
|------|------|
| ツールバー | パネルの表示切替 |
| 操作パネル | モード、スロット / ID、トラック適用、プリセット、数値入力 |
| **グラフ** | **残りの高さすべて。**上端に反転と表示リセットだけを置いています |
| Lua 欄 | 生成・手入力コード |
| 検索 / ステータス | 使用箇所検索（開いたときのみ）、状態表示 |

- **操作パネルと Lua 欄は境界をドラッグして高さを変えられます。** 縮めた分はグラフが受け取ります
- 操作パネルは折りたたみ節に分かれています。**数値入力はグラフで代替できるので既定で畳んで**
  います（アンカー列と区間種別が要る **マルチベジェ / 標準(複合)** だけ既定で開く）。
  開閉状態はモードごとに覚えます

### ウィンドウ操作

- **プリセット** ボタン: 左のプリセットパネルの表示／非表示を切り替え
- **Lua** ボタン（v0.8.0〜）: 下の Lua 欄の表示／非表示。閉じるとその高さはグラフへ回ります
- **集中** ボタン（v0.8.0〜）: グラフ集中モード。操作パネルと Lua 欄をまとめて畳み、
  ウィンドウのほぼ全部をグラフにします。ハンドルを細かく触りたいときに使います
- **✕** ボタンまたは **Esc**: 開いているポップアップ・使用箇所検索パネル・プリセットパネルを一括で閉じる
- プリセット一覧から項目を選ぶと、読み込み後にプリセットパネルが自動で閉じます

### コンパクトレイアウト（v0.5.6〜）

ウィンドウ幅に応じて UI が自動調整されます。

| 幅 | 挙動 |
|----|------|
| **520px 未満** | モード選択をコンボボックス化、ボタン・ラベルを短縮、スライダーを縦並び、説明文を圧縮 |
| **380px 未満** | スクリプトエディタの行番号・プレビュー非表示、モード名を略記 |

狭いドッキング配置でも主要機能（編集・適用・Live）が使えるようになっています。
グラフの高さは幅ではなく**ウィンドウの残り高さ**で決まります（下限 120〜160px）。

## 概要

CurveEditor2 は専用のトラックバー移動スクリプト **`@カーブエディタ2.tra2`** と連携します。移動方法の表示名は **「カーブエディタ2」** です。

| ファイル | 役割 | 配置先 |
|---------|------|--------|
| `CurveEditor2.aux2` | イージング編集 GUI（本プラグイン） | `Plugin\CurveEditor2\` |
| `@カーブエディタ2.tra2` | トラックバー補間本体（Live・組み込みセクション） | `Script\CurveEditor2\` |
| `CurveEditor2Presets.lua` | プリセット（初回は ScriptCurve から読込可） | `Plugin\CurveEditor2\` |
| `CurveEditor2Live_active.lua` | Live 同期（自動更新） | `Plugin\CurveEditor2\` |
| `{プロジェクト名}.CurveEditor2Live.lua` | プロジェクト別 Live 保存 | プロジェクトフォルダ |
| `{プロジェクト名}.CurveEditor2Library.json` | プロジェクト別カーブライブラリ | プロジェクトフォルダ |

> 旧プロジェクトの **スクリプトカーブ** 適用箇所は、使用箇所検索で引き続き検出できます。新規適用は **カーブエディタ2** を使用してください。

## 導入

1. [Releases](https://github.com/HexBrowns/CurveEditor2/releases) から `HexBrowns.CurveEditor2-v0.9.10.au2pkg.zip` をダウンロードし、AviUtl2 のプレビューへドラッグ&ドロップする
   （手で置くなら、中の `Plugin` フォルダと `Script` フォルダを、AviUtl2 のデータフォルダ（既定は `C:\ProgramData\aviutl2`）へコピーする）。
   次の 2 つが置かれます
   - `Plugin\CurveEditor2\CurveEditor2.aux2`
   - `Script\CurveEditor2\@カーブエディタ2.tra2`
2. AviUtl2 を再起動する（起動中に置いた場合も、再起動するまで読み込まれません）
3. **表示** メニュー → **CurveEditor2** でウィンドウを開く

v0.9.7 までは zip を展開して置く形でした。上書きで入れ替えて構いません（Live・プリセット・ライブラリはそのまま使えます）。

Live とプリセットのファイルは、データフォルダの `Plugin\CurveEditor2\` に作られます。
`.tra2` はデータフォルダの場所を `obj.getinfo("script_path")` から求めて Live を読むので、
データフォルダが既定と違う環境（本体の隣に `data` フォルダを置くポータブル版など）でも Live が読める見込みです（ポータブル版では未確認）。

### ビルド（開発者向け）

リポジトリのルートで [aviutl2-cli](https://github.com/sevenc-nanashi/aviutl2-cli) の `au2` を実行します。
`release/` に、AviUtl2 のプレビューへドラッグ&ドロップして導入できるパッケージ（`.au2pkg.zip`）ができます。

```powershell
au2 release
```

- Rust **1.92 以降** が必要（`rust-toolchain.toml` 参照）
- 依存: `aviutl2` / `aviutl2-eframe` **0.47**
- 開発者向けの説明はリポジトリの `DEVELOPMENT.md` にあります

## 使い方

### 1. トラックバーへの適用（推奨）

1. タイムラインで適用先オブジェクトを選択（フォーカス）  
   → ウィンドウ表示中は、オブジェクトを選び直す・動かす・名前を変えるなどしたときに、トラック一覧を自動取得します（手動の **「トラック取得」** も残しています）。
   ウィンドウを隠している間は取得せず、出したときに、そのとき選んでいるオブジェクトのトラックを取得します
2. CurveEditor2 でカーブを編集（**Live** は既定 ON。編集内容は約 0.15 秒間隔で同期）
3. コンボボックスからトラックを選択
4. 表示中の **適用先:** ラベルを確認（Live #N または組み込みセクション）
5. **「このトラックに適用」** をクリック  
   （Live の場合はスロットへ書き込んだうえで移動方法を設定します）

> **v0.8.3 より前は、移動方法がまだ付いていない（固定値の）トラックへ適用できませんでした**
> — 「数値トラックではない」と出て弾かれます。v0.8.3 では開始値＝終了値の移動として
> 書き込むので、あとはオブジェクト設定で終了値を変えるだけです。
>
> **v0.8.2 より前は、オブジェクトの 2 番目以降に置いた効果へ適用できませんでした**
> （「適用しました」と出るのに移動方法が変わらない）。フィルタ効果として積む
> マルチセクションスクリプトで目立ちます。v0.8.2 で修正し、書き込めなかった場合は
> 成功と報告せずエラーを表示します。

移動方法の形式:

- Live: `開始,終了,カーブエディタ2@カーブエディタ2,0|N`（加減速・時間制御を付けると `加減速|N|時間制御`）
- Live の別セクション: `区間ごとにスロットを進める@カーブエディタ2` / `全体で1本@カーブエディタ2`（設定は同じ形）
- 組み込み: `開始,終了,セクション@カーブエディタ2,0`（例: `バウンス@カーブエディタ2`）

すでに Live のセクションが付いているトラックへ「このトラックに適用」すると、
**セクションはそのままでスロット番号だけを差し替え、加減速・時間制御の設定は残します**（v0.9.1〜）。
ほかの移動方法から切り替えたときは `カーブエディタ2@カーブエディタ2` の `0|N`（設定なし）で書きます。

中間点のあるオブジェクトへの適用（v0.9.10〜）:

- 固定値のトラックは、点（開始・中間点・終了）の数だけ同じ値を並べて書きます。v0.9.9 までは値 2 つで書いていたので、中間点のあるオブジェクトでは点の数と合いませんでした
- **中間点無視** を付けたトラック（と、値が 2 つの再生範囲）へ適用すると、中間点無視を残したまま書きます（オブジェクト全体で 1 本のカーブ）。v0.9.9 までは中間点無視が外れ、最初の区間だけ動いて後は止まりました

#### Live の 3 つの移動方法（`.tra2` v1.10〜）

中間点を置いたときのカーブの掛け方は、**移動方法の一覧で選びます**（Basic_S の「区間ごとに時間制御」
「全体で時間制御」と同じ分け方）。3 つとも設定は **スロット** だけで、トラックの加速・減速・時間制御が使えます。
**v1.0 で作ったトラック（`カーブエディタ2`）は「加減速なし・時間制御なし」として読まれ、見た目は変わりません。**

| 移動方法 | 中間点があるとき |
|------|------|
| **カーブエディタ2** | 中間点で区切った区間ごとに、同じカーブを最初から掛ける（v1.0 と同じ） |
| **区間ごとにスロットを進める** | k 番目の区間（0 始まり）は **スロット + k** のカーブ。区間ごとに違う緩急にしたいとき |
| **全体で1本** | 開始点から終了点までの時間に 1 本のカーブを掛け、中間点の値の間は直線でつなぐ |

| トラックの設定 | 内容 |
|------|------|
| **加速・減速** | どちらも OFF・加速だけ ON = カーブそのまま / 減速だけ ON = カーブを点対称に折り返す（イン ⇄ アウト） / 両方 ON = 前半そのまま・後半を折り返したインアウト |
| **時間制御** | カーブエディタ2 と 区間ごとにスロットを進める は区間ごとに、全体で1本 は全体に掛かる（Basic_S の 区間ごとに／全体で時間制御 と同じ） |

> 区間の扱いを「スロットの次の設定値」にしなかったのは、AviUtl2 が**保存されている設定値の数と
> スクリプトの設定値の数が合わないと、全部を既定値に戻す**ためです（設定値を 2 つにした試作で、
> v1.0 のトラックのスロットがすべて 1 に戻ることを実機で確かめました）。

同じスロットのカーブを、加速・減速のチェックだけでイン版とアウト版に使い分けられます。
折り返しは Basic_S の基本緩急と同じ考え方で、式に渡す始点・終点の値も入れ替わります
（下の `log_ratio` が折り返しても対数補間のままになるのはこのため）。

プリセット名が組み込みセクション名（バウンス、ベジェ等）と一致していると、適用先は Live ではなくその組み込みになります。適用帯の **適用先:** 表示で確認できます。

#### 手動（移動方法ダイアログから選ぶ場合）

1. トラックバー **移動方法** → **カーブエディタ2**
2. セクション **@カーブエディタ2**（Live）または組み込みセクションを選択
3. Live の場合、パラメータ **スロット番号** を CurveEditor2 のスロット / ID と一致させる
4. CurveEditor2 でカーブを編集し **「スロットに反映」** を押す（または **Live** ON）

#### トラックオーバーレイ（v0.5.0〜）

1. フォーカス中オブジェクトで **「トラック取得」** → 対象トラックを選択
2. **オーバーレイ** チェック ON（デフォルト OFF）

グラフ下に、選択トラックの **開始値〜終了値** の範囲へ編集中カーブを重ねて表示します。

- 灰色の線: 現在のトラックバー上の実際の値（キャッシュ。**更新** ボタンで再描画）
- 橙色の線: 編集中カーブを開始・終了値にマッピングしたプレビュー

スクリプトモードでは、既知の生成形式（`bezier` / `spring` / `bounce` / マルチ・複合）なら近似プレビュー、それ以外は線形（`t`）になります。

### 2. 編集モード

| モード | 内容 | グラフ操作 |
|--------|------|-----------|
| **ベジェ** | CSS cubic-bezier 相当（x1,y1,x2,y2） | オレンジの制御点をドラッグ |
| **マルチベジェ** | 複数アンカー。各区間は **自動 ease-in-out（種類固定）** | 緑アンカーをドラッグ / ダブルクリックで追加・削除 |
| **振動** | 減衰振動 spring（ζ, ω） | プレビューのみ |
| **バウンス** | 標準 bounce out | プレビューのみ |
| **標準(複合)** | 区間ごとに **直線/ベジェ/振動/バウンスを切り替え** 可能 | アンカー・区間別ベジェ制御点をドラッグ / 区間クリックで選択 |
| **スクリプト** | Lua コード直接編集 | 近似プレビュー（既知形式のみ） |

UI では選択中モードの下に一言説明が出ます（ホバーでも同文）。**マルチベジェ**と**標準(複合)**の差は「区間の種類を変えられるか」です。

グラフは共通で **ホイール: 上下移動**、**Ctrl+ホイール: 縦ズーム**、**Shift+ホイール: 左右移動**、**Ctrl+Shift+ホイール: 横ズーム**（カーソル位置を中心に拡縮）、**右ドラッグ: パン**、**「表示リセット」ボタン**で初期表示に戻せます（v0.5.7〜）。
v0.8.0 からこの操作一覧は常時表示をやめ、グラフ右上の **操作?** にホバーすると出ます（1 行ぶんグラフを広げるため）。

グラフのグリッド（v0.9.0 で分割数を変更可能に）:

- グラフ右上の **グリッド**（狭い幅では **格子**）の数値で**分割数**を 2〜100 に変えられます（縦横共通、既定 20 = 5% 刻み）。
  ドラッグで増減、ダブルクリックで直接入力。値はプロジェクトに保存されます
- 分割線: 細い灰色 / 端（0%・100%）と 4 等分線: 太めの灰色 / 中央（50%）: 緑色（分割数が偶数のとき）
- 0〜1 の外（オーバーシュートする値の範囲）にも同じ刻みで、ごく薄い線が出ます
- 線の間隔が詰まりすぎると細い線は省略されます（スナップは効きます）
- **Shift を押しながらハンドルをドラッグすると、グリッドの交点に吸着**します。
  マルチ／標準(複合)で **Shift を押しながらダブルクリック**すると、交点にアンカーを追加します。
  端点（t=0 / t=1）は値だけが吸着します

#### カーブの反転（v0.8.0〜）

グラフ上端の 3 ボタンで、編集中のカーブを折り返します。
**同じボタンをもう一度押すと元の形に戻ります**（2 回で恒等）。

| ボタン | 内容 | 式 |
|--------|------|-----|
| **左右反転** | 時間を反転する。始点と終点の値が入れ替わる（登場 ↔ 退場） | `y'(t) = y(1-t)` |
| **上下反転** | 値を折り返す。始点と終点の中間が軸 | `y'(t) = (始点値 + 終点値) - y(t)` |
| **In/Out入替** | 左右＋上下（180°回転）。**始点・終点はそのまま**でイーズイン ⇄ イーズアウトが入れ替わる | `y'(t) = (始点値 + 終点値) - y(1-t)` |

- 例: ease-in `bezier(t, 0.42, 0, 1, 1)` → **In/Out入替** → ease-out `bezier(t, 0, 0, 0.58, 1)`
- 対応モードは **ベジェ / マルチベジェ / 標準(複合)**。
  **振動・バウンス・スクリプトではボタンが無効**になります（形をパラメータで折り返せないため）
- 標準(複合)の **左右反転**は、アンカーと区間の並びに加えて各区間の形も反転します。
  ただし **振動区間・バウンス区間の形だけは折り返せない**ので元のまま残り、
  ステータスにその件数が出ます。**上下反転はどの区間種別でも厳密**です

#### ベジェモードの操作

- 灰色の端点: t=0 / t=1 は固定、**Y はドラッグで変更可**（v0.7.3〜）
- オレンジの制御点: P1・P2 をドラッグしてカーブ形状を調整
- 点線は制御ハンドルを示します
- Lua 欄で `return bezier(t, x1, y1, x2, y2)` を手入力し **「Luaから反映」**（またはフォーカス解除）でも設定できます
- 端点 Y を既定（0 / 1）以外にすると、生成 Lua は `y0`/`y3` 付きの絶対座標ベジェになります
- **注意**: 曲線の終点 y が 1 でない場合（例: 弧で y3=0）でも、最終フレームは曲線どおり評価されます（v0.7.4 の tra2 修正）。トラックの「終了値」キーそのものは編集上の数値として残りますが、再生時の最終フレームは曲線の y3 側に従います

#### マルチベジェモードの操作

- 灰色端点: **t=0 / t=1 は固定**、Y はドラッグで変更可
- 緑のアンカーをドラッグして位置 (時間, 値) を変更
- グラフ上をダブルクリック → 新規アンカー追加
- アンカー上をダブルクリック → 削除（端点除く）
- 各区間は ease-in-out ベジェで滑らかに接続されます

> 区間ごとに直線・ベジェ・振動・バウンスを個別に選びたい場合は「標準(複合)モード」を使用してください。

#### 標準(複合)モードの操作

- 1本のカーブの中で **区間ごとに種類（直線・ベジェ・振動・バウンス）を切り替え** られます
- 灰色端点: **t=0 / t=1 は固定**、Y はドラッグで変更可。緑（または選択中は黄）のアンカーをドラッグして位置を変更
- グラフ上をダブルクリック → アンカー追加
- アンカー上をダブルクリック → 削除（端点除く）
- 区間クリックで選択。ベジェ区間は制御点ドラッグ（端点間の y 差が 0 でもハンドル操作可）、振動区間は ζ / ω スライダー
- 「リセット」で初期状態（端点のみ・ベジェ1区間）に戻せます

### 3. カーブライブラリ（ID 1〜524288）とスロット

- **ID連携**（既定 ON）: **スロット番号＝カーブ ID**。UI では **「スロット / ID」** が1つの数値コントロールになります
- ID連携 OFF のときだけ、スロットとカーブ ID を別々に操作できます
- **ID読込 / ID保存 / ID削除**: ライブラリ操作
- 左パネル「カーブライブラリ」に保存済み ID 一覧

保存先:

- プロジェクトファイル（`.aup2`）内のプラグインデータ
- プロジェクトフォルダの `{プロジェクト名}.CurveEditor2Library.json`（2026-09-27 から。それより前はフォルダに 1 つの `CurveEditor2Library.json`）

### 4. 使用箇所検索

- **使用箇所** ボタンで、現在開いているプロジェクト内を検索
  - **今のシーンは編集中の状態**（保存していない変更も含む）、**ほかのシーンは保存済みの `.aup2`** を読みます（0.9.5 から）
  - ほかのシーンで変えたところは、保存してから検索すると反映されます
- 検索対象は現在の編集状態から自動判定:
  - プリセット名が組み込みセクション名（バウンス、ベジェ等）と一致 → そのセクション
  - それ以外 → Live（`@カーブエディタ2`）+ 現在のスロット番号
- 結果は下部パネルに表示。**行をクリック**すると該当オブジェクトにフォーカス
- 旧 **スクリプトカーブ** 適用箇所も検出できます

### 5. 元に戻す（v0.9.0 で復活）

エディタ内のカーブ編集は、ツールバーの **↶ / ↷** または **Ctrl+Z / Ctrl+Y（Ctrl+Shift+Z）** で元に戻す／やり直すことができます。

- **1 回の操作が 1 段**です（ドラッグ 1 回、ボタン 1 回、数値の入力 1 回）。ドラッグ途中の細かい動きは段になりません
- 対象はカーブの形とモード・Lua 本文。**表示（ズーム・パン）、選択、グリッド分割数の変更は段になりません**
- 反転・アンカーの追加削除・座標パネル・区間種別・プリセット読込・ID読込も戻せます（v0.8.0 までは一部が戻せませんでした）
- 最大 100 段。プロジェクトを開き直すと履歴は消えます
- ショートカットは **CurveEditor2 のウィンドウを操作しているときだけ**効き、そのとき本体側の元に戻すは動きません。
  タイムラインなどを操作しているときの Ctrl+Z は、これまでどおり本体の「元に戻す」です
- **Lua 欄に入力中の Ctrl+Z は、Lua 欄の文字の取り消し**になります（カーブの段ではありません）
- **「このトラックに適用」の取り消しは本体の「元に戻す」**で行います。トラックへの書き込みは本体の Undo に登録されます

> **v0.8.1〜0.8.3 で削除していた理由は誤りでした。** 「本体の元に戻すが直前の操作を戻さない」不具合を
> CurveEditor2 の Ctrl+Z 横取りのせいと見て削除しましたが、実際の原因は別のプラグイン
> （`reset_frame_selection_on_focus.aux2` と `PaletteHistory.aux2`）でした。
> どちらも、別のオブジェクトをクリックしてそのまま動かしたときに本体の編集処理へ割り込み、
> その操作の Undo を本体が捨ててしまいます。CurveEditor2 は関係していないことを確認したので戻しました

### 6. スクリプトエディタ

- 行番号ガター、簡易バリデーション、先頭数行プレビュー
- **全モード**で Lua 欄を手編集できます
- ベジェ／振動／バウンス／マルチベジェ／標準(複合)は **「Luaから反映」** またはフォーカス解除でモデルへ反映（生成形式と対称）
- スクリプトモードはコード自体が正。既知形式ならグラフに **近似:** ラベル付きでカーブを表示

#### 式から読める値（`.tra2` v1.10〜）

式の戻り値は今までどおり **比率**（0 = 始点の値、1 = 終点の値）です。そのうえで次を読めます。

| 名前 | 内容 |
|------|------|
| `st` / `ed` | その区間の始点・終点の値（加速・減速で折り返したときは入れ替わる。全体で1本 では開始点と終了点） |
| `index` / `num` / `slot` | 区間番号（0 始まり）/ 開始・中間・終了点の総数 / 評価中のスロット |
| `log_ratio(t[, 原点])` | 対数補間（Basic_S の 対数補間 と同じ値）になる比率。拡大率・ズームのように倍率で見る値向け。始点と終点が同符号でない・原点にある・等しいときは `t` |
| `to_ratio(値)` | 値を比率に直す（終点＝始点のときは 0）。`return to_ratio(st * (ed / st) ^ t)` のように値で式を書ける |

`st` / `ed` を使う式は、エディタのグラフ（値を知らない 0〜1 のプレビュー）とは形が一致しません。

- 式のエラーは、同じスロット・同じ内容につき **1 回だけ** ログに出ます（v1.10〜。それまでは評価のたびに出ていた）。
  式を直して Live に反映されると、まだ壊れていればもう一度 1 回出ます
- Live ファイルの内容が変わらない間は式をコンパイルし直しません（作者の計測で 1 回の評価が約 6 分の 1）

### 7. Live スロット

- **Live** チェック: 編集内容を約 0.15 秒間隔で `Plugin\CurveEditor2\CurveEditor2Live_active.lua` へ同期（**既定は ON**、v0.7.1〜）
- **「スロットに反映」**: いまの編集内容を現在スロットへ即書き込み（プリセット読込とは別操作）。
  v0.8.0 から **「トラック適用」節の「このトラックに適用」の隣**にあります（プリセット節ではありません）
- プロジェクト保存時: `{プロジェクトdir}\{プロジェクト名}.CurveEditor2Live.lua` に永続化（プロジェクトごとのファイル。2026-09-27 から）
- **プロジェクトを開いたとき**: そのプロジェクトの Live のスロットだけを読み、すぐ `CurveEditor2Live_active.lua` へ書き出します。
  開いた時点から、そのプロジェクトで保存したカーブで描画されます（2026-09-27 から）。読む順は次のとおりです
  1. `{プロジェクト名}.CurveEditor2Live.lua`
  2. 無ければ、フォルダに 1 つの `CurveEditor2Live.lua`（以前の保存先。引き継ぐだけで書き換えません。次に保存すると 1. ができます）
  3. どちらも無いとき（新しいプロジェクトなど）は、直前の `CurveEditor2Live_active.lua` を引き継ぎます
- 以前は、別のプロジェクトを開いた後にこのプロジェクトを開くと、「スロットに反映」を押すまで別のプロジェクトのカーブで描画されていました
- 以前は Live とライブラリがフォルダに 1 つで、同じフォルダに置いたプロジェクトどうしでカーブが共有されていました。
  今はプロジェクトごとに分かれるので、同じフォルダに置いてもかまいません
- **外から書かれたスロットも残ります**（0.9.7 から）。ほかのツールなど、エディタの外から Live に足したスロットは、
  保存（1 分ごとの自動バックアップを含む）のときに取り込んでから書き戻します。同じスロットをエディタでもいま反映していた場合は、エディタの側を残します。
  以前は次の保存でエディタが持っている中身に書き戻され、外から足したスロットが消えていました

### 8. プリセット

- 左パネルから選択するとプリセットを **読み込み**（編集コードに反映）
- **保存**: プリセット名を入力 → 保存
- **削除**: プリセット名を指定して削除
- 操作パネルの **プリセット** 節は既定で畳まれています（名前欄・保存・削除）。
  **スロットに反映** は v0.8.0 から **トラック適用** 節へ移動しました
- カテゴリ／プリセット一覧／カーブライブラリはそれぞれ独立してスクロールします（v0.7.2〜）

プリセットファイル: `Plugin\CurveEditor2\CurveEditor2Presets.lua`（未作成時は ScriptCurve のプリセットを読込可）

## 旧 ScriptCurve からの移行

CurveEditor2 は、作者の以前のプラグイン ScriptCurve（`ScriptCurveEditor.aux2`、C++ 製）の後継です。

- ウィンドウ名: **ScriptCurve エディタ** → **CurveEditor2**
- トラックバーには専用の `@カーブエディタ2.tra2` を使います。新しく適用するときは **カーブエディタ2** を使ってください
- 旧プロジェクトの **スクリプトカーブ** 適用箇所は、使用箇所検索で引き続き検出できます
- Live / プリセットは `Plugin\CurveEditor2\` に置きます。プリセットのファイルがまだ無いときは、ScriptCurve のプリセットを読み込めます

---

## 制限事項・既知の制限

- AviUtl2 の終了時に、ログへ `[aviutl2_eframe] Egui thread panicked` で始まる行が出ることがあります。上流（aviutl2-eframe）の問題で、終了時に出るだけなので動作に害はありません
- D&D によるトラックバーへの直接適用: 非対応（「このトラックに適用」で代替）
- 使用箇所検索のシーン切替: 現在シーン内のオブジェクト照合のみ
- 本格的な Lua シンタックスハイライト: 簡易プレビューのみ
- スクリプトモードのグラフ近似: 既知の生成形式のみ（任意式の完全評価は非対応）
- エディタ内の Undo は本体の Undo とは別の履歴です（プラグインから本体の Undo に積む API はありません）
